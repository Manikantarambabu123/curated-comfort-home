# Homefront Showcase

Build the FIRST PAGE of a premium, modern Interior Furniture & Home Décor e-commerce website.

IMPORTANT:

Build ONLY the Home Page for now.

Do NOT build the entire website.

Do NOT create the dashboard, product details, checkout, orders, customization, or other pages yet.

However, create the navigation structure/buttons so they can later link to those pages.

The page must look production-ready, not like a basic demo or template.

Prioritize visual quality, usability, spacing, typography, responsive design, and premium furniture-store aesthetics.

BRAND / VISUAL DIRECTION

Create a sophisticated modern furniture brand with a warm, premium, editorial feel.

Color palette:

Warm ivory / cream background

Soft beige

Natural wood brown accents

Charcoal / near-black text

Very subtle muted green or terracotta accent if needed

Avoid:

Bright saturated colors

Excessive gradients

Cheap-looking shadows

Excessive rounded cards

Cluttered layouts

Generic SaaS styling

Typography:

Use an elegant modern serif/display font for major headings.

Use a clean modern sans-serif font for body text, navigation, buttons, prices, and UI.

Create a clear typography hierarchy.

Overall feeling:
"Premium furniture showroom + modern online shopping experience."

HEADER / NAVIGATION

Create a sticky or intelligently persistent header.

Left:

Elegant text-based logo such as "LUMORA" or another premium furniture brand name.

Center navigation:

Shop

Furniture

Home Décor

New Arrivals

Collections

Right:

Search icon

Wishlist icon

Account icon

Shopping bag/cart icon with item count

Include a subtle secondary navigation or category menu if it improves usability.

Header should remain clean and spacious.

On mobile:

Logo

Search

Cart

Hamburger menu

HERO SECTION

Create a large, visually striking hero section.

Use a high-quality interior/furniture lifestyle image showing a beautifully designed modern living room.

Hero copy:

"Designed for the way you live."

Supporting text:

"Thoughtfully crafted furniture and home décor that brings comfort, character, and timeless style into your space."

Primary CTA:
"Shop Furniture"

Secondary CTA:
"Explore Collections"

The hero should feel editorial and premium.

Use large typography with plenty of whitespace.

Do NOT cover the entire image with excessive text.

TRUST / VALUE STRIP

Immediately below the hero, create a minimal horizontal value section with 3–4 benefits.

Examples:

"Free Delivery"
"Easy Returns"
"Custom Furniture"
"Secure Payments"

Use simple line icons.

Keep this section visually subtle.

SHOP BY CATEGORY

Create a visually strong category section.

Heading:
"Shop by Category"

Subheading:
"Everything you need to create a space that feels like home."

Create large visual category cards for:

Sofas & Seating

Beds & Bedroom

Dining

Tables

Storage

Home Décor

Each card should have:

Large image

Category name

Small "Explore" interaction

Use high-quality interior/furniture imagery.

The cards should feel like part of a premium catalog, not generic UI cards.

FEATURED PRODUCTS

Create a product section titled:

"Made to Live With"

Subheading:

"Furniture designed for everyday comfort and lasting style."

Display 4–6 products in a responsive grid.

Each product card should include:

Product image

Product name

Short category/type

Price

Star rating

Wishlist heart icon

Optional "New" or "Bestseller" badge

Quick Add button or Add to Cart interaction

Example products:

"Arlo Lounge Sofa"
"Linea Oak Dining Table"
"Form Lounge Chair"
"Vera Upholstered Bed"
"Solace Side Table"
"Arc Storage Cabinet"

Use realistic furniture pricing.

Add:
"View All Products"

Product cards should have subtle hover interactions:

Image zoom/alternate image

Wishlist interaction

Quick add

Do not over-animate.

PERSONALIZED RECOMMENDATIONS

Since this website specifically supports personalized recommendations, include a section that introduces this feature.

Heading:

"Furniture That Fits Your Style"

Text:

"Tell us what you love, and we'll curate pieces that work beautifully with your space."

CTA:
"Find My Style"

Create a visually interesting split layout:

One side: lifestyle interior image

Other side: short explanation + CTA

This should communicate that the store provides personalized product recommendations.

COLLECTION / EDITORIAL SECTION

Create a premium editorial banner.

Heading:

"The Warm Minimal Collection"

Text:

"Natural textures, soft forms, and timeless pieces designed to create calm, inviting spaces."

CTA:
"Explore Collection"

Use a large full-width interior image.

This section should look similar to a premium furniture magazine/editorial website.

CUSTOMER CUSTOMIZATION FEATURE

Create a section highlighting custom furniture.

Heading:

"Make It Yours"

Text:

"Choose the fabric, finish, dimensions, and details to create a piece made specifically for your space."

CTA:
"Customize Your Furniture"

Use a split image/text layout.

This feature should be visually prominent because custom orders are an important part of the website requirements.

CUSTOMER REVIEWS

Create a clean testimonial section.

Heading:

"Loved by Homeowners"

Display 3 customer reviews.

Each review should include:

5-star rating

Short review

Customer name

Optional city

Keep the design elegant and believable.

NEWSLETTER / EMAIL SECTION

Create a premium newsletter signup section.

Heading:

"Bring Better Design Home"

Text:

"Get new collections, styling inspiration, and exclusive offers delivered to your inbox."

Include:

Email input

"Subscribe" button

Keep this section minimal.

UX REQUIREMENTS

Make the entire Home Page responsive.

Desktop:

Wide layouts

Large furniture imagery

Comfortable whitespace

Tablet:

Adjust grids and typography naturally

Mobile:

Single-column layouts where appropriate

Horizontally scrollable category/product sections where useful

Large touch-friendly buttons

No horizontal overflow

Navigation must be easy to use

Images must maintain good aspect ratios

INTERACTIONS

Add subtle, professional interactions:

Smooth hover states

Product image hover

Wishlist toggle

Add-to-cart feedback

Smooth navigation

Button hover states

Subtle section reveal animations

Avoid excessive animation.

IMPORTANT IMPLEMENTATION RULES

Use reusable components for:

Header

Footer

Product Card

Category Card

Buttons

Section headings

Rating component

Wishlist button

Use realistic placeholder product data and high-quality furniture imagery.

Do not use broken image URLs.

Do not use lorem ipsum.

All visible text should be realistic and polished.

The final result should look like a real premium furniture e-commerce brand that could be launched publicly.

Before finishing, check:

Visual consistency

Responsive behavior

Spacing

Typography hierarchy

Button usability

Image quality

Navigation clarity

Accessibility

No horizontal overflow

No obvious template/demo appearance

Again: ONLY BUILD THE HOME PAGE at this stage.
